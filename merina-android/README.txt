Merina Android app (WebView shell)
1. Install Android Studio (free) and open this folder (File > Open).
2. Wait for Gradle sync, then  Build > Build APK(s)  (or Generate Signed Bundle / APK for a release version).
3. Copy app/build/outputs/apk/debug/app-debug.apk to the phone and install it (allow "install unknown apps").
4. First start: type your server address (e.g. https://merina.yourcompany.com). Change it later from the top-right menu (Server address).
Editing, access rights, updates and the Database are all on the server - the app just shows it.
